# Журнал исправлений Golden Set

В ходе независимой проверки Review были обнаружены
и исправлены 13 первоначальных разметок.

Типы изменений:
- 10 случаев корректировки координат рамок;
- 2 случая добавления пропущенных рамок;
- 1 случай удаления рамки.

Все исправления выполнены ревьюерами и дополнительно
проверены командой. Команда одобрила все 13 результатов
без внесения дополнительных изменений.

## Содержимое

- `corrections.csv` - журнал 13 исправлений.
- `build_corrections.py` - скрипт формирования журнала.

Для каждого исправления сохранены:
- идентификатор фотографии;
- исходные рамки BBox;
- исправленные рамки Review;
- тип изменения;
- пояснение характера изменения;
- решение команды.

Пояснения о типах изменений сформированы автоматически
на основе сравнения исходных и исправленных рамок.
Они не являются дословными комментариями ревьюеров.

Исходные ответы доступны в `bbox/results/`,
результаты проверки - в `review/results/`,
итоговая разметка - в `golden_set/golden_set.jsonl`.
