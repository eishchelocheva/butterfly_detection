# Golden Set

## Итоговая разметка

Golden Set содержит проверенную разметку 400 фотографий из iNaturalist.

- Всего фотографий: 400
- Фотографий с бабочками: 318
- Фотографий без бабочек: 82
- Всего bounding boxes: 341

Итоговая разметка хранится в `golden_set.jsonl`.

Для каждой фотографии сохранены `photo_id` и `boxes`.
Координаты рамок нормализованы в диапазоне от 0 до 1.

## Формирование Golden Set

Первичная разметка выполнялась исполнителями BBox.
Затем все 400 фотографий прошли независимую проверку Review.

По результатам Review:
- 387 разметок приняты без исправлений.
- 13 разметок исправлены ревьюерами.

Все 13 исправлений были дополнительно проверены командой
и признаны корректными.

Команда также проверила остальные итоговые разметки.
Дополнительных изменений в координаты рамок
после Review не вносилось.

Golden Set сформирован на основе утверждённых
результатов Review.

## Контроль качества

Исполнители BBox и Review не пересекались.

Исходные ответы исполнителей сохранены в `bbox/results/`.
Результаты проверки сохранены в `review/results/`.

Итоговая разметка используется как эталон
для сравнения моделей детекции бабочек.
