# Результаты ревью и выгрузки

Файлы ответов и подготовленные задания создаются командой `review/tasks_api.py`. Описание команд, формата и отбора ответов приведено в [README проекта ревью](../README.md) и [документации API](../configs/api.md).

Выгрузки могут содержать идентификаторы исполнителей и исключены из репозитория. При работе с ними соблюдайте правила доступа к данным.

## Результаты с заменёнными ID исполнителей

В [`anonymized/`](anonymized/) находятся результаты экзамена и основного пула review. Поле `worker_id` заменено последовательным номером; один номер соответствует одному исполнителю в обоих файлах. Исходные ID и таблица соответствия в репозиторий не включены. Остальные поля сохранены, поэтому данные являются псевдонимизированными: идентификаторы заданий и другая контекстная информация могут позволять повторную идентификацию при наличии дополнительных данных.
