# Итоговая посылка в Яндекс Контест

## Выбранная модель

Для итоговой разметки экзаменационного датасета использовалась
модель OWLv2 base с порогом уверенности 0.5.

Модель выбрана после сравнения трёх моделей:
- Grounding DINO tiny
- OWLv2 base
- Qwen3-VL-2B-Instruct

На Golden Set модель Qwen показала более высокий F1@IoU 0.5,
однако не смогла обработать одну фотографию.

Для итоговой посылки была выбрана OWLv2 base,
которая обработала все фотографии без ошибок.

Код и результаты экспериментов находятся в директории `models/`.

## Итоговый результат

- Экзаменационных фотографий: 400
- Модель: OWLv2 base
- Порог уверенности: 0.5
- Результат в Яндекс Контесте: 10/10 баллов

Файл `submission.jsonl` содержит автоматически полученные
предсказания модели без ручного исправления рамок.
