# BBox: разметка бабочек

Команды выполняются из корня репозитория.

Инструкция читается из `instructions/annotator.html`. Дополнительные библиотеки не нужны.

## Основные команды

```bash
# Посмотреть план проекта и пулов без обращения к API
python3 bbox/create_project.py

# Создать закрытые пулы или продолжить создание (заполните api_token в bbox/configs/api.json)
python3 bbox/create_project.py --apply

# Подготовить задания: 20 фото для пилота, 380 для основного пула
python3 bbox/tools.py prepare

# Преобразовать ответы исполнителей в JSONL
python3 bbox/tools.py convert export.tsv --out bbox/results/annotations.jsonl
```

`--apply` создаёт пустые закрытые пулы. Загрузку заданий и открытие пулов выполняйте в кабинете. Существующие файлы результатов не перезаписываются: для повторной подготовки или конвертации задайте новый `--out`.

`results/api_state.json` создастся при первом `--apply`. Сохраните его для продолжения работы с новым проектом.
