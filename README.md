# Обнаружение бабочек на фотографиях (butterfly detection)

Командный проект по курсу «Сбор и разметка данных для машинного обучения».

## 1. Описание проекта

Цель проекта - подготовить эталонную разметку фотографий с бабочками, сравнить готовые модели обнаружения объектов и выбрать наиболее подходящую модель на основе измеренных метрик качества.

В рамках проекта мы собираем датасет, организуем разметку изображений в Яндекс Заданиях, проводим независимую проверку и исправление ошибок, формируем golden set и сравниваем модели на полученных данных.

**Основные этапы:**

Сбор фотографий $\rightarrow$ BBox-разметка $\rightarrow$ Review $\rightarrow$ Golden Set $\rightarrow$ Сравнение моделей $\rightarrow$ Выбор итогового решения.

### Постановка задачи

На вход алгоритм получает фотографию. На выходе - прямоугольные рамки всех взрослых бабочек. Если бабочек нет, ответ - пустой список.

Правила разметки:

- Каждая бабочка выделяется отдельной рамкой, даже если несколько объектов перекрываются.
- Рамка плотно охватывает видимые части объекта: крылья, тело, усики и лапки.
- Если бабочка закрыта другим объектом или обрезана краем фотографии, выделяется её видимая часть. Скрытые части не достраиваются.
- Размечаются все взрослые дневные и ночные бабочки; разделять их на группы не нужно.
- Другие насекомые, гусеницы, куколки и тени не размечаются.
- Неоднозначный объект требует дополнительного разбора. Ошибка загрузки изображения не считается отсутствием бабочки.

Эти правила используются при первичной разметке, проверке результатов и оценке моделей.

## 2. Сбор датасета

Для проекта собран датасет из 400 фотографий с платформы [iNaturalist](https://www.inaturalist.org/).

Все изображения имеют лицензию CC0. Для сбора использовался iNaturalist API.

### 2.1. Состав датасета

Датасет включает 320 фотографий с бабочками и 80 фотографий без взрослых бабочек.

| Категория | Количество |
|---|---:|
| Одна хорошо заметная бабочка (`single_clear`) | 150 |
| Маленькая бабочка (`small`) | 70 |
| Несколько бабочек (`multiple`) | 13 |
| Частично закрытая бабочка (`occluded`) | 50 |
| Сложный фон (`complex_background`) | 37 |
| Другие насекомые (`other_insects`) | 40 |
| Природные объекты без бабочек (`nature_negative`) | 40 |
| **Всего** | **400** |

Категории были выбраны для проверки моделей на изображениях разной сложности.

Фотографии с маленькими бабочками, перекрытиями и сложным фоном позволяют оценить работу моделей в сложных условиях. Изображения с несколькими бабочками нужны для проверки обнаружения нескольких объектов на одном кадре.

Отрицательные примеры используются для оценки ложных срабатываний на других насекомых и природных объектах.

Категории определялись при ручном отборе фотографий и не заменяют эталонную разметку рамками.

### 2.2. Процесс сбора

Фотографии получены через метод `GET /v1/observations` из [iNaturalist API](https://api.inaturalist.org/v1/docs/).

Сбор данных состоял из следующих этапов:

1. Получение фотографий-кандидатов через API.
2. Проверка лицензии `CC0` для каждой фотографии.
3. Ручной просмотр и распределение изображений по категориям.
4. Формирование итоговой выборки.
5. Скачивание оригинальных изображений.
6. Проверка файлов и поиск дубликатов с использованием SHA-256 и pHash.
7. Объединение положительных и отрицательных примеров.

Для фотографий сохранены идентификаторы, ссылки на исходные наблюдения и сведения о лицензиях.

## 4. Независимая проверка (Review)

**Статус: ревью разметки выполнено в Яндекс Заданиях. [Материалы ревью](review/README.md).**

Ревьюеры видят исходное изображение и предложенные рамки. Проверка направлена на обнаружение:

- пропущенных бабочек;
- лишних рамок;
- неточных границ;

Автор первичной разметки не проверяет собственную работу.

Ревьюеры проходили экзамен с ручной проверкой. По его результатам часть исполнителей не была допущена к основной разметке.

По результатам проверки ответ может быть принят, отправлен на исправление или передан на ручной разбор.

## 5. Golden Set

**Статус: завершён. Все 400 фотографий проверены, Golden Set сформирован.**

Ревью разметки всех 400 фотографий выполнено. Итоговая разметка по ответам основного пула представлена ниже.

По ответам основного пула review:

| Вердикт | Ответов | Доля |
|---|---:|---:|
| Одобрена исходная разметка | 387 | 96,75% |
| Отклонена и выполнена переразметка | 13 | 3,25% |
| Спорный случай | 0 | 0% |
| **Всего** | **400** | **100%** |

| Показатель | Значение |
|---|---:|
| Уникальных фотографий | 400 |
| Фотографий со статусом «Есть бабочки» | 318 |
| Фотографий со статусом «Бабочек нет» | 82 |
| Итоговых рамок и размеченных бабочек | 341 |

В каждом ответе со статусом «Есть бабочки» есть итоговые рамки. Число размеченных бабочек рассчитано по числу рамок; все итоговые разметки дополнительно проверены командой. Исправления 13 отклонённых ответов выполнены ревьюерами и одобрены командой без дополнительных изменений.

Для каждой фотографии сохраняются рамки всех взрослых бабочек либо подтверждённое отсутствие объектов.

Итоговая разметка основана на первичных ответах исполнителей и независимой проверке.

Итоговые аннотации сохранены в [`golden_set/golden_set.jsonl`](golden_set/golden_set.jsonl). Журнал 13 исправлений и скрипт его формирования находятся в [`golden_set/corrections/`](golden_set/corrections/).

Golden set используется как эталон при оценке моделей.

### 6.5. Выбор итоговой модели

По F1@IoU 0.5 и F1@IoU 0.75 лучший результат
показала Qwen3-VL-2B-Instruct.

Однако для итоговой отправки в Контест
команда выбрала OWLv2 base с порогом 0.5.

Причины выбора:

- отсутствие ошибок обработки на Golden Set;
- меньше ложных рамок на отрицательных фотографиях;
- более высокая скорость обработки по сравнению с Qwen;
- возможность использовать модель для стабильного
  автоматического формирования предсказаний.

Этот выбор является компромиссом между качеством
детекции, скоростью и надёжностью, а не выбором
модели с максимальным F1.

OWLv2 была запущена на отдельном экзаменационном
датасете. Посылка получила 10/10 баллов в Контесте.

## 7. Итоговые предсказания

**Статус: посылка отправлена в Яндекс Контест, результат 10/10 баллов.**

Для итоговой разметки выбрана OWLv2 base с порогом уверенности 0.5. Файл посылки и описание результата находятся в [`contest/`](contest/).

После выбора итоговой конфигурации модель была запущена на отдельном экзаменационном датасете из 400 фотографий, который не входит в собранную командой выборку.

Предсказания формируются автоматически, без ручного исправления рамок.

Результат сохраняется в формате JSONL: одна строка на фотографию.

```json
{"photo_id": 123, "boxes": [{"left": 0.1, "top": 0.2, "width": 0.3, "height": 0.4}], "error": null}
{"photo_id": 124, "boxes": [], "error": null}
```

Координаты рамок нормализованы в диапазон от 0 до 1.

Пустой список `boxes` означает успешную обработку изображения, на котором модель не обнаружила бабочек. Ошибки обработки фиксируются отдельно и не заменяются пустым списком.

Итоговые предсказания сохранены в [`contest/submission.jsonl`](contest/submission.jsonl).
